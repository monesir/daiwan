# أدوات موقع الديوان (Aldiwan.net Tools)

يحتوي هذا المستودع على أداتين مفيدتين لمُحبي الشعر العربي ومستخدمي موقع [الديوان](https://www.aldiwan.net/):

---

## 1. إضافة متصفح كروم (الديوان - تصميم اقتباس)
إضافة للمتصفح لتحسين تجربة القراءة وتسهيل نسخ الأبيات الشعرية.

### المميزات:
- **الوضع الليلي (Dark Mode):** قراءة مريحة للعين في الأوقات المتأخرة.
- **تغيير السمات والخطوط:** إمكانية تغيير خط القصائد إلى خطوط عربية جميلة (مثل "عام الشعر العربي") أو إضافة روابط لخطوط مخصصة.
- **النسخ الذكي للأبيات:** نسخ القصيدة بشكل مرتب وأنيق عبر تحديد الأبيات والضغط بزر الفأرة الأيمن (Right-Click) واختيار "نسخ الأبيات بشكل منسق"، ليتم النسخ بطريقة (الصدر - مسافة - العجز) وكل بيت في سطرين.
- **تحكم مرن بحجم الخط:** تكبير وتصغير حجم خط القصيدة بكل سهولة دون تكبير باقي عناصر الموقع.
- **إخفاء/إظهار الزخارف:** إمكانية إخفاء الزخارف الشعرية لتجربة قراءة أنظف.
- **تخصيص الألوان:** تغيير لون النص ولون الزخارف لتناسب ذوقك.

### طريقة التثبيت:
1. قم بتحميل المستودع وفك الضغط عنه.
2. افتح متصفح كروم وانتقل إلى `chrome://extensions/`.
3. قم بتفعيل **Developer mode** من الزاوية العلوية.
4. اضغط على **Load unpacked** واختر مجلد `aldiwan_extension`.

---

## 2. مؤرشف موقع الديوان الذكي (Python Scraper)
برنامج متكامل لتحميل وأرشفة جميع القصائد من الموقع بضغطة زر.

### المميزات:
- **واجهة رسومية (GUI):** سهلة الاستخدام لاختيار مجلد الحفظ ومتابعة التقدم.
- **تخطي الحماية:** يستخدم مكتبة `cloudscraper` لتخطي حماية Cloudflare.
- **تنظيم ذكي للمجلدات:** يتم حفظ القصائد كالتالي: `العصر أو الدولة / اسم الشاعر / القصيدة.txt`.
- **استخراج السيرة الذاتية:** سحب نبذة عن الشاعر وحفظها في `نبذة عن الشاعر.txt`.
- **تنسيق الشعر العمودي:** يتعرف على القصائد العمودية وينسقها بشطرين.
- **حفظ التقدم:** عند إيقاف البرنامج وتشغيله مجدداً، سيتخطى الملفات المحملة مسبقاً ليكمل من حيث توقف.

### المتطلبات وطريقة الاستخدام:
- Python 3.7+
- تثبيت المكتبات: `pip install -r requirements.txt`
- تشغيل الواجهة: `python app_desktop.py`
- نسخة سطر الأوامر (CLI): `python aldiwan_crawler.py`
